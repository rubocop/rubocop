### Changes

* [#16346](https://github.com/rubocop/rubocop/issues/16346): Report a `ParserEngine` that cannot parse the target Ruby version, or that needs the `parser` gem when it is not installed, as a configuration error instead of a backtrace. ([@bbatsov](https://github.com/bbatsov))
* [#16346](https://github.com/rubocop/rubocop/issues/16346): Require RuboCop AST 1.54, which makes `prism` the default parser engine for Ruby 3.3+ when Prism 2.0 or later is installed. ([@bbatsov](https://github.com/bbatsov))
* [#16346](https://github.com/rubocop/rubocop/issues/16346): Make `Cop::Base#parse` use the Ruby version and the parser engine of the source under investigation. ([@bbatsov](https://github.com/bbatsov))
* [#16346](https://github.com/rubocop/rubocop/issues/16346): Parse the gemspec file with Prism when looking for the target Ruby version, unless `ParserEngine` is `parser_whitequark`. ([@bbatsov](https://github.com/bbatsov))
* [#16346](https://github.com/rubocop/rubocop/issues/16346): Make `rubocop -V` show the parser engine that is used when `AllCops: ParserEngine` is not set. ([@bbatsov](https://github.com/bbatsov))
